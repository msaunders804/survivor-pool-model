How this works

The model suggests which team to pick for each of your entries each week. This app shows the plan and keeps track of what you've actually picked, so next week's plan knows which teams are already used.

The weekly routine

  1. Mon night
    Games finish.

    Last week's results are final once Monday's game is done.

  2. Tuesday
    Mark last week's results Results page

    Set each pick to Won or Lost. A lost pick knocks that entry out, and the model stops planning for it.

    Update the numbers This week's numbers

    Set the new week, the entries still alive in the pool (from Splash), and the pot. The model reads these when it runs.

    Paste the league percentages Ownership page

    Paste from Splash's Stats tab. For now this only shows on the Board. The model doesn't use it yet.

  3. Wed noon ET
    The model runs by itself.

    It takes a minute or two. Refresh the Board afterwards for the new plan and expected payout. It runs before Thursday night's game so a Thursday pick is possible. It's 11am ET after daylight saving ends on Nov 1.

  4. Wed–Sun
    Enter your picks on Splash, then record them Picks page

    Type each pick and tick "on Splash" once it's entered. Saving here is what tells next week's run which teams you've used. A pick you save is never overwritten by the model.

  5. Before games
    Want fresher odds?

    The Wednesday plan uses Wednesday's odds. To refresh it closer to kickoff, ask whoever manages Render to click “Trigger Run” on the weekly job.

What each page does

Board

The model's recommended picks, grouped by team, with its expected payout. Open “Entered vs. the model” to compare with what's actually entered.

Picks

Enter or change each entry's pick for this week, and mark when it's on Splash.

Ownership

Paste the league's pick percentages from Splash's Stats tab.

Results

Mark each past pick Won or Lost. Entries with a loss show as “Out.”

This week's numbers

The current week, the entries still alive, and the pot. The model uses these.

Good to know

  • The model's picks are suggestions. You can enter something different. The Board shows how many entered picks differ.
  • If you forget to save a pick, the model's suggestion is saved for you as that entry's pick when it runs, so teams you've used don't get forgotten. Check the Picks page if you went a different way.
  • A tie counts as a loss.
  • The first page load can be slow (up to about 30 seconds) if nobody has used the app for a while.
  • If the Board says “no model recommendation yet,” the weekly run hasn't happened for the current week. Check that the week on “This week's numbers” is right.
