How this works

The model suggests which team to pick for each of your entries each week. This app shows the plan, tracks what you've actually picked, and tells the next run which teams each entry has used. The Board's checklist shows what's left to do each week.

The weekly routine

  1. Tue
    Glance at last week's results Results

    Won and Lost fill in by themselves from the final scores. Fix any that look wrong. An entry with a loss is out, and the model stops planning for it. A tie counts as a loss.

    Paste Splash's availability report Availability

    Copy the report from Splash and paste it in. The model uses it as the real state of the rest of the pool, and it also sets the live-entry count. The week has already turned over by Tuesday morning, so the paste lands on the right week.

  2. Wed noon ET
    The model runs by itself.

    It takes a minute or two. Refresh the Board for the new plan. Running on Wednesday leaves time for a Thursday-night pick. After daylight saving ends on Nov 1 it runs at 11am ET.

  3. Wed–Sun
    Enter picks on Splash

    Use the Board's plan; each pick shows its opponent, like “LAR vs ARI”. Splash locks every remaining game at Sunday 1pm ET, and earlier games (like Thursday night) at their own kickoff.

    Only if you pick a different team: update it Picks

    The model's picks are saved for you automatically. If you enter exactly those on Splash, there's nothing to do here. If you go a different way for an entry, change that entry on the Picks page and save. Next week's plan uses it to know which teams that entry has used. Ticking “on Splash” is optional.

    One case to watch: if the model is re-run later in the week and suggests a new team, the saved pick stays the earlier one. If you follow the new suggestion, update it on Picks too.

What each page does

Board

This week's checklist, the model's picks grouped by team with each opponent and lock time, and the model's expected payout. Open “Entered vs. the model” to compare with what's actually entered.

Picks

Each entry's saved pick for this week, which starts as the model's. Only needed when you enter a different team on Splash. The dropdown only offers teams that entry hasn't used and that aren't on a bye.

Availability

Where Splash's availability report goes each week. It feeds the model.

Results

Each past pick's Won or Lost, filled in from final scores. Change one by hand if needed. Entries with a loss show as “Out.”

Settings

The week, live entries and pot. The week and live entries fill in by themselves, so this is only for corrections.

Good to know

  • The model's picks are suggestions. You can enter something different. The Board shows how many entered picks differ.
  • If you forget to save a pick, the model's suggestion is saved as that entry's pick when it runs, so used teams aren't forgotten. Check the Picks page if you went a different way.
  • Want fresher odds before kickoff? Whoever manages Render can click “Trigger Run” on the weekly job.
  • The first page load can be slow (up to about a minute) if nobody has used the app for a while.
